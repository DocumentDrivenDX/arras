# Downstream browser qualification

Run `npm run qualify:downstream -- ../dist/arras-0.6.0-py3-none-any.whl` from `ui/` to extract one wheel cohort, install that wheel into a fresh temporary Python environment, build and pack the neutral theme fixture against the wheel-carried npm declarations, and launch both the installed prebuilt-page route and an outside Vite host importing the wheel-carried Arras npm tarball plus packed theme package. The fixture invokes the qualification CLI from that extracted npm package. Chromium and axe checks cover Explore and Operate in light and dark color schemes. The runner checks declared same-origin theme assets, role tokens, contrast pairs, app-owned themed controls, keyboard behavior, and screenshots. This is browser evidence for the fixture and tested package cohort, not a production host certification.

Screenshots and the JSON cohort receipt are written under `evidence/<platform>/` for review. Visual baselines are separate files under `baselines/<platform>/`; macOS qualification compares each screenshot to its existing baseline and fails if one is missing or differs in more than one percent of pixels. Baselines are compared only on macOS; other platforms mark visual comparison skipped while retaining all browser, accessibility, token, contrast, and keyboard gates. To intentionally update baselines, pass `--update-baselines` after the wheel argument on macOS and review the image changes before keeping them. The receipt records exact selected wheel/npm/theme/runner hashes and runtime versions. The Arras and theme packages are installed from the selected tarballs, while React, Vite, TypeScript, Playwright, and axe are installed from the public npm registry into the temporary host.
