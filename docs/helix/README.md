# Design documents

Arras is an open-source interface to an ontology. These documents describe what it is and why; the code and
its CI-run tests are the source of truth for what works.

| Where | What |
| --- | --- |
| `00-discover/` | Product vision |
| `01-frame/` | PRD, concerns, principles, feature specs, user stories |
| `02-design/adr/` | Architecture decision records |
| `02-design/contracts/` | The contracts (CONTRACT-001 and following) the code and tests are held to |
| `02-design/architecture.md` | Architecture overview |
| `03-test/` | Test plan |

[`glossary.md`](glossary.md) defines the external systems and Arras terms the documents use. Release history
is in the repository's `CHANGELOG.md`; open work is in `ROADMAP.md`.
