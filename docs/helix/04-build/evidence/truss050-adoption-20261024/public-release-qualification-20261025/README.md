# Public release qualification evidence

This directory preserves the minimal public-download closure for Arras 0.6.1. The receipts are copied byte-for-byte from the completed public downloaded-release qualification; hashes and exact source/tag/wheel bindings are recorded in `retention-index.json`. Private originals and workflow ZIPs are held separately and are not part of this repository evidence.

The proof is limited to the exact wheel and recorded cohorts. It does not imply PyPI or npm publication (both optional publisher jobs were skipped), broader platform support, production managed-service behavior, or native macOS behavior.
